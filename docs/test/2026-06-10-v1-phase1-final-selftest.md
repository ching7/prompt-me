# PromptMe V1 阶段① 全链路自测清单（2026-06-10）

> 在 **Chrome 网页**（`flutter run -d chrome`）逐项验收。每条勾 ✅/❌，❌ 的写现象反馈。
> 链路：**捕获 → 收件箱 → 加入今日 → 待办执行（福格 + 番茄）→ 正反馈积分 → 复盘**，外加 **AI 开关**贯穿。

## 0. 启动
- [ ] `flutter run -d chrome` 能起、无报错；默认进**待办** Tab。
- [ ] 底部 3 Tab：收件箱 / 待办 / 复盘；右上角有**设置齿轮 ⚙️**（每个 Tab 都在）。

## 1. 捕获 → 收件箱
- [ ] 收件箱 Tab 点 **+** → 输入文本、选领域 → 保存 → 卡片进收件箱（新→旧）。
- [ ] 顶栏 `★ 总积分` 应 **+2**（捕获即加分，静默无动画）。

## 2. 加入今日
- [ ] 收件箱里把一条「加入今日」→ 该条从收件箱消失、出现在**待办** Tab 今日待办区。
- [ ] 待办 Tab 直接点 **+** 加一条 → 进今日待办，`★` 同样 +2。

## 3. 待办执行 · 福格闭环
- [ ] **左滑「我做到了」** → 背景**绿**、庆祝弹层（🔥连续 +1 + **「+10 分」**）→ 任务进已完成；`🔥`/`★` 即时跳。
- [ ] **右滑「太难了」** → 背景**红** → 选原因（忘记/太累/没动力）→ 任务**降级成微习惯**：卡片出现绿色 `🌱 微习惯·已降级 N 次` + `来自原任务`。
- [ ] **同一任务连续两次**选**同一**原因「太难了」→ 卡上出现 `🩺 总卡在『…』`（MAP 诊断）；两次选**不同**原因 → 不显（平票）。

## 4. 番茄钟
- [ ] 待办卡点 `🍅` → 进**专注屏**：倒计时环 + 任务名 + **预估 🍅（1–4 可点）** + 放弃/暂停 + 提前完成。
- [ ] 点预估 **3** → 返回后卡上 `🍅` 显 `N/3`。
- [ ] **提前完成 +1 🍅** → 完成态显「番茄完成 +1 / +10 分」→ 返回后卡 `🍅`+1、`★`+10。
- [ ] **放弃** → 直接退出；`🍅` **不**加、`★` **不**加（控制台有 `tomatoAbort`，不计分）。

## 5. AI 开关（贯穿）
- [ ] 进**设置**（右上齿轮）→「启用 AI」开关**默认关**。
- [ ] **关 AI** 时右滑降级 → 微习惯是**本地文案**，且按原因不同（太累/没动力/忘记给不同方向）；控制台 `[AI] 降级·未启用 → 本地兜底`。
- [ ] **开 AI + 填 key + 测试连接通过** → 再降级 → 微习惯变 **AI 生成**；控制台 `[AI] … HTTP 200 … AI 返回`。

## 6. AI 整理今日（prioritize）
- [ ] 待办屏「**AI 整理今日**」按钮：**关 AI** → 弹层显「开启 AI…去设置」引导。
- [ ] **开 AI** → 弹层 loading → 显「今天先做：…」+ 每条任务的四象限建议。

## 7. 复盘屏
- [ ] 复盘 Tab：**今日小结**（✓完成 / 🍅番茄 / 😣太难了 数对得上当天操作）。
- [ ] **累计**：🔥连续 / ★总积分 / 🩺 MAP 模式（够次数显主因，否则「暂无明显模式」）。
- [ ] AI 区：**关 AI** 显引导；**开 AI** 点「生成 AI 复盘」→ loading → 每条挣扎任务「诊断 → 建议」（需先有今日已降级且仍待办的任务）。

## 8. 边界 / 回归
- [ ] 刷新页面（重载）后数据还在（Drift WASM 持久化）。
- [ ] 关 AI 全程无任何网络请求（DevTools Network 里没有 chat/completions）。
